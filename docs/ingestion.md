# Stage 06 ingestion contract

This is the future ingestion contract authorized by Hugo in Stage 03, not an implementation or permission to start Stage 06. Follow curation approval before bulk downloads.

- `npm run ingest -- --build --out media-out` runs with no secrets; local mode also holds none. Until `scripts/ingest.ts` exists the pipeline creates `{"photos":[]}`. Once ingestion exists, an empty manifest must fail live smoke checks.
- Generate optimized AVIF/WebP widths, thumbnail and 1200×630 OG image using sharp. The six-photo evaluation's compression settings are not visually approved; final parameters require design/content review. Do not use R2, Functions, Workers or paid image transforms.
- Hash source bytes plus versioned transform settings into `photos/<nasa-id>/<hash>/`. Retain approved source and output SHA-256 checksums in tracked metadata; validate regenerated bytes before packaging. Fail if remote sources or tool output drift. Never overwrite a release's approved identity. Pin the generation toolchain.
- The generated `manifest.json` follows `scripts/pages-media.ts`. Each photo contains `nasaId`, hexadecimal `hash`, nonempty `variants` (relative hashed file paths), and `original`. Use `selectOriginal` only after verifying the NASA source and measuring the original bytes.
- `original` for up to 26,214,400 bytes: `{ "kind": "local", "path": "photos/ID/HASH/original.jpg", "sourceUrl": "https://images-assets.nasa.gov/...", "sizeBytes": 123 }`. Copy the exact source bytes unchanged and verify checksum equality. Never call an optimized/recompressed image an original.
- Above that size: `{ "kind": "nasa", "sourceUrl": "https://images-assets.nasa.gov/...", "sizeBytes": 33973862 }`. This example size is illustrative. Do not include a local `path` or the oversized binary in the output. Preserve the exact measured integer and verified final HTTPS NASA URL. Validate redirects as well as the initial URL; a nasa.gov suffix check is necessary but not provenance evidence.
- The gallery's original-download control labels an external NASA download explicitly in both languages, with its size. Optimized display images remain same-origin. Implement that control in Stage 07; Stage 03 does not change the gallery UI or sample schema.
- `package-media.ts media-out dist` replaces `dist/media`, verifies referenced files and local original sizes and checks all files, including nonmedia. Maximum 20,000 files, 26,214,400 bytes each. No automatic paid fallback. Reject symlinks, non-regular files, Worker entrypoints and Functions. Generated binaries and artifacts stay out of Git.
- Each preview/staging/production artifact owns its HTML and media. An exact production rollback restores the earlier Pages deployment. Tag rebuilds remain behind the existing release gate and must verify approved source/output checksums; failure must not silently publish changed media.
- Extend smoke checks to decode representative generated AVIF/WebP/thumbnail/OG files, verify local-original checksums and confirm an explicit external link for a real oversized original. Stage 03 already checks deployed manifest, image bytes and local-original lengths when photos exist.

# Manual checks for Hugo

Verify actual staging and production images, correct download headers/links, full-artifact limits on Pages and an earlier production rollback with matching HTML/media. No local fixture test substitutes for live deployment or approval App/source-binding verification.
